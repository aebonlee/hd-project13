## 반영하지 않은 부분 — decodeId() 의 "Priority" 표기
안상욱님 예시("ID: 0x18F00401 → Priority: 18 PGN: F004 SA:01")는 ID 최상위 바이트(0x18)를
그대로 "Priority" 라고 부르고 있으나, 실제 SAE J1939-21 규격상 Priority 는 3비트 값(0~7)이고
0x18F00401 의 진짜 우선순위는 6 임 (`decodeId()` 로 확인). 기존 코드는 PDU1/PDU2 구분까지
정확히 구현한 표준 준수 버전이라, 그의 단순화된 예시에 맞춰 다운그레이드하지 않음.
필요하면 "최상위 바이트"를 보여주는 표시를 별도 열로 추가하는 방향으로 다시 논의.
