J1939 CAN 사양 정리 자동화

전장품마다 따로 오는 사양서(Word·PDF·Excel)를 올리면 ID · PGN · CAN Channel · Source Address · Period 를 뽑아 엑셀 한 장으로 모읍니다. 양식이 업체마다 달라도 됩니다.

1. 사양서를 올리세요

Word(.docx) · PDF · Excel(.xlsx) 을 한 번에 여러 개 올릴 수 있습니다. 모델·전장품이 달라도 한 표로 모입니다.

    어떻게 정리하나

    사양서에 다섯 가지가 다 있는 일은 드뭅니다. 보통 ID 나 PGN 중 하나만 적혀 있습니다. ID 가 PGN 보다 상위여서 ID 안에 PGN 이 들어 있으므로, 둘 중 하나만 있어도 정리가 됩니다.

    사양서에 있는 것채울 수 있는 것비고
    IDPGN · Source Address · 우선순위 ID 를 뜯으면 그 안에 다 들어 있습니다
    PGN— 우선순위와 SA 를 모르므로 ID 는 만들지 않습니다
    CAN Channel · Period— 계산으로 얻을 수 없습니다. 사양서에 있어야 합니다
    계산으로 채운 값에는 표에서 계산 표시가 붙습니다. 문서에 적혀 있던 값과 신뢰도가 다르기 때문입니다. 엑셀에도 「계산으로 채운 항목」 열로 남습니다.

    어긋난 사양서는 고치지 않고 알립니다

    사양서에 ID 와 PGN 이 둘 다 적혀 있는 일이 있습니다. 사람이 손으로 옮기다 한쪽만 고치면 둘이 어긋나는데, 그대로 정리하면 틀린 표가 만들어집니다. 그래서 계산해 맞춰 보고 어긋나면 「검토필요」에 양쪽 값을 다 적어 알립니다. 어느 쪽이 맞는지는 원본을 봐야 알기 때문에 고쳐 주지 않습니다.

    파일이 서버로 올라가지 않습니다. 읽기도 엑셀 만들기도 전부 이 브라우저 안에서 끝납니다 — 사내 사양서를 다루는 도구라 이 점이 중요합니다.
